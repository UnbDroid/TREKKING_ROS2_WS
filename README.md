# TREKKING_ROS2_WS
Workspace padrão de ROS2 (Jazzy) para uso na categoria Trekking Pro

Biblioteca funcionando agora é necessario apenas clonar o repositorio, e posteriormente rodar esse comando para baixar todos os arquivos:
git submodule update --init --recursive

Favor clonar rf2o_laser_odometry e sllidar_ros2 no src outra vez antes de dar build
